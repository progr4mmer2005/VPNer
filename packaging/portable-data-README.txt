VPNer хранит здесь настройки, подключения и скачанные компоненты, пока эта папка лежит рядом с vpner.exe.

Удалите папку data, чтобы программа хранила всё в профиле Windows (%LOCALAPPDATA%\VPNer).

Пароли зашифрованы ключом учётной записи Windows: на другом компьютере их нужно будет ввести заново.
Контейнер WSL для Cisco/OpenVPN регистрируется в Windows и на новом компьютере создаётся заново.
